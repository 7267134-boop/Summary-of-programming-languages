מבוא למנגנון Memoization ב-PROC

שאלה זו דורשת שדרוג של שפת "ייינגור" (PROC - פרק 3, עמ' 74-81) כך שהפעלות של פרוצדורות (call-exp) יעשו שימוש בזיכרון מטמון גלובלי.

  • עקרונות השפה: שפת PROC היא שפה פונקציונלית טהורה. אין בה מנגנון של זיכרון (Store). לכן, המטמון מיושם "מאחורי הקלעים" ברמת מפרש השפה (Scheme) על ידי משתנה גלובלי.
  • המטמון (the-cache): שומר רשימה של תתי-רשימות במבנה מדויק: (proc arg result).
  • ניהול (LRU): בכל קריאה לפרוצדורה, המפרש בודק קודם במטמון. מציאה תגרום לשליפה מהירה ולקידום הרשומה לראש התור. כישלון יוביל לחישוב ההפעלה ושמירת התוצאה במטמון למען קריאות עתידיות.
דרישת השאלה:
"ממשו את init-cache – פרוצדורה ללא פרמטרים המאתחלת את זיכרון המטמון לראשונה להיות ריק."
; init-cache: () -> update the-cache to empty cache (define init-cache (lambda () (set! the-cache '())))
דרישת השאלה:
"ממשו את search-cache – המקבלת פרוצדורה (proc) וארגומנט (arg) ומחפשת האם קיימת תוצאת הפעלה שלהם במטמון. אם כן, מוחזר האינדקס של מיקומם. אחרת, מוחזר #f."
; search-cache : return #f if prc,arg not in cache ; or index (from 0) found in the cache (define search-cache (lambda (prc arg) (letrec ((search-inner (lambda (lst idx) (cond ((null? lst) #f) ((and (equal? (car (car lst)) prc) (equal? (cadr (car lst)) arg)) idx) (else (search-inner (cdr lst) (+ idx 1))))))) (search-inner the-cache 0))))
דרישת השאלה:
"ממשו את פעולת העזר remove-at המוחקת איבר מאינדקס מסוים, ואת rearrange-cache המעדכנת את זיכרון המטמון כך שהאיבר מהאינדקס הנתון מועבר לתחילתו (מנגנון LRU)."
; remove-at: removing element at index n from list lst (define (remove-at lst n) (if (zero? n) (cdr lst) (cons (car lst) (remove-at (cdr lst) (- n 1))))) ; rearrange-cache: move element at idx to beginning (define rearrange-cache (lambda (idx) (let ((item (list-ref the-cache idx))) (set! the-cache (cons item (remove-at the-cache idx))))))
דרישת השאלה:
"ממשו את add-cache – המקבלת פרוצדורה, ארגומנט ותוצאה, ומוסיפה אותם כאיבר חדש לתחילת המטמון. הפרוצדורה בודקת קודם אם יש מקום, ואם לא – מפנה מקום על ידי מחיקת האיבר האחרון."
; add-cache: add new procedure call result to the cache (define add-cache (lambda (prc arg result) (if (= (length the-cache) cache-size) (set! the-cache (remove-at the-cache (- cache-size 1))) #f) (set! the-cache (cons (list prc arg result) the-cache))))
דרישת השאלה:
"ממשו עדכון להתנהגות הביטוי call-exp – תחילה יש לבדוק אם קיימת במטמון תוצאה מאותה פונקציה וארגומנט. אם כן – להחזירה, לקדמה ולהדפיס הודעה. אחרת – לחשב, להוסיף למטמון ולהחזיר את התוצאה."
; new implementation for call-exp with memoization (call-exp (rator rand) (let ((prc-val (value-of rator env)) (arg (value-of rand env))) (let ((prc (expval->proc prc-val))) (let ((idx (search-cache prc arg))) (if idx (let ((result (caddr (list-ref the-cache idx)))) (rearrange-cache idx) (eopl:printf "procedure call result ~s found in cache :-)~%" result) result) (let ((result (apply-procedure prc arg))) (add-cache prc arg result) result))))))
